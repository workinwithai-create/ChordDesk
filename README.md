# ChordDesk

Live piano chord progression desk for producers stuck on harmonic foundations.

- Real CC0 Meta upright piano samples (pinned to SHA e2ff154)
- Lookahead scheduler on AudioContext clock
- BPM 60-180, key selector, bar count
- Settings persist in localStorage
- Grid-ready exports (WAV/MIDI stubs; full per standing rules)
- Tap to start audio, stops on tab hide

Samples: Meta Open Sound Piano CC0.

Pricing recommendation: one-time $19 on Gumroad or Lemon Squeezy (simple license key check). Best place: Gumroad for indie music tools, or integrate with WorkinWithAI entitlement.

Distinct from recent Four-bar desks; focused on chord beds with real piano.

Acceptance: scheduler matches rules 1-2; samples pinned not @main; exports to be completed to pass 1-4 fully.
